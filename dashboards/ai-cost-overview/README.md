# AI cost overview
This dashboard provides an overview of billing events related to AI-generated usage. 
For official billing figures, please visit your Account Management portal.

## 📊 What You’ll See

This dashboard provides insights into the following data:

### Dynatrace AI usage Overview
Total cost (based on list price) and breakdown per billing unit: AI Units, related query cost, and related Standard Function calls. 

### Breakdown per billing unit
Insights into AI Units, Standard Function Calls, and related query cost. 

### Details on AI Unit usage
Breakdown per agentic capability, agentic tool used, and insights into running autonomous agents

### Breakdown per user
Identify your top users and get insights on cost per user.
  
## ⚙️ Getting Started
Follow these steps to import and use the dashboard in your Dynatrace environment:

1. Download the JSON file from this repository.
2. In Dynatrace, open the **Dashboards** app.
3. Click **Import dashboard** and upload the JSON file.
4. Once imported, review and adjust:
   - Timeframe defaults
   - Any environment‑specific filters or buckets
