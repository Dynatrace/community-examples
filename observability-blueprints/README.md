# 🗺 Observability Blueprints

End-to-end reference setups that combine multiple artifacts (dashboards, workflows, configs) into a complete, opinionated solution for a scenario. Each blueprint is its own subfolder with a README listing every component and a full setup path.

**Before contributing:** follow the [repository standards](../STANDARDS.md) and the [quality bar](../CONTRIBUTING.md), and start from the [README template](../templates/EXAMPLE-README-template.md).
