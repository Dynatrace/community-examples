📐 How We Calculated This — Methodology

K8s namespace utilisation query (run in a Dynatrace Notebook)

timeseries {
  cpu_usage    = sum(dt.kubernetes.container.cpu_usage),
  cpu_requests = sum(dt.kubernetes.container.requests_cpu),
  mem_usage    = sum(dt.kubernetes.container.memory_working_set),
  mem_requests = sum(dt.kubernetes.container.requests_memory)
}, by: {k8s.cluster.name, k8s.namespace.name},
from: now()-15m
| fieldsAdd
    avg_cpu_usage    = arrayAvg(cpu_usage),
    avg_cpu_requests = arrayAvg(cpu_requests),
    avg_mem_usage    = arrayAvg(mem_usage),
    avg_mem_requests = arrayAvg(mem_requests)
| filter isNotNull(avg_cpu_requests) and avg_cpu_requests > 0
| fieldsAdd
    cpu_efficiency_pct = round((avg_cpu_usage / avg_cpu_requests) * 100, decimals:1),
    mem_efficiency_pct = round((avg_mem_usage / avg_mem_requests) * 100, decimals:1)
| sort cpu_efficiency_pct asc
| limit 20
